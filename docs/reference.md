# 參考資料：BombParty 系遊戲的實測行為與我們的對照

整理日期 2026-10-23。實測對象是 https://bombparty.app/ 的 Practice 模式（Chrome 實際操作，玩了三題：答對一題、答錯一次、讓炸彈爆一次）。jklm.fun 的 BombParty 只看到房間與規則面板，需要三人才能開局，未實際玩過。Krillion 的 Puffer Party 只看了大廳，不是字母題型，與本專案無關。

## bombparty.app Practice 實測

練習參數（開始前的設定頁）：Timer 10s（滑桿）、Lives 3（滑桿）、String length 3（滑桿）、Difficulty（Easy / Medium / Hard）、Long-word bonus（12 字母以上加分，預設開）、Overtime（計時逐題縮短，預設關）。

對局行為：

- 每題獨立計時。答對後倒數立刻回到完整時間並換新提示；答錯不重設時間。
- 炸彈圖中央直接顯示剩餘秒數。剩約 5 秒炸彈轉暗紅，3 秒時整個畫面邊緣轉紅。
- 答錯：輸入框下方出現紅字「Word must contain "cta".」，輸入內容保留並反白。
- 爆炸：扣一顆心，連對歸零，換新提示並重新計時，輸入框下顯示「CTA got you. A valid answer: INJECTABLE」，只列一個範例詞。
- 頂部四格：Round、Score、Streak、Lives。右側面板為答題紀錄，每個詞帶稀有度標籤（COMMON）與得分（LIST +12）。
- 下方字母鍵盤，用過的字母亮起（對應「用完所有字母回一顆心」的規則）。

## 本專案自有的設計

- 三個模式：注音縮寫（給每字注音第一個符號）、指定開頭、聲調。詞長一律 2 到 4 字。
- 詞庫：教育部《重編國語辭典修訂本》與《成語典》，共約 14.5 萬個 2 到 4 字詞、5,431 個成語。取辭典第一個讀音顯示注音，驗證時接受任一讀音。
- 注音縮寫取每字注音的第一個符號，不分聲母韻母（零聲母字取韻母），不分聲調。
- 難度門檻逐模式、逐詞長訂定（見 web/js/core.js 的 MIN_ANSWERS），因為各模式的提示稀疏度差很多。指定開頭模式的提示最稀疏，3 字開頭只有約 419 題有三個以上的解。
- 計分：字數減 1，成語另加 3。
- 結束流程：先跳結算彈窗（這局的答對、時間到、答錯輸入、最佳詞，以及沒答出來的題目與範例答案），按「看結算」才進結算頁，Esc 與點背景都不能略過。結算頁有排名與逐題回顧。

## 種子碼與分享（參考 pokemon-zarbi）

做法沿用 /Users/stevenchao/Documents/Repos_self/pokemon-zarbi 的成績碼：src/rng.js（hashSeed、mulberry32、makeRandom，直接複製到 web/js/rng.js）與 src/share.js 的格式慣例（base64url、`~` 分欄、壞碼回 null、貼連結或貼碼都能解、網址用 `?c=`）。

- 固定題序：`promptOrder(pool, seed)` 先把提示排序再用種子洗牌，第 n 題固定是第 n 個。題目與誰答對、答多快完全無關，用完整個池之前不重複。
- 種子碼：6 碼英數（不含易混字元），也可自訂（英數或中文，最多 24 字，英文轉大寫）。設定頁留白就是每次隨機；對局頁顯示種子。
- 分享碼：`1~模式~詞長~難度~種子~每題秒數~生命~旗標~詞庫簽章[~得分~答對~撐過題數]`，base64url。旗標 L 長詞加分、O 縮短計時、S 符號集滿回血。有成績的碼，朋友載入時會看到分享者的分數，打完同一份題目後結算頁顯示勝負。
- 詞庫簽章是詞數的 36 進位，兩邊詞庫不同時提醒題目可能不一致。
- 開局前就能分享：設定頁一進來就有種子（不再留白），下方的分享連結隨設定與種子即時更新；對局中、結算彈窗、結算頁都有複製鈕。種子輸入接受全形英數（NFKC 轉半形），不合法時在欄位旁提示。載入朋友的碼期間，對方的設定不寫進自己的本機偏好，取消挑戰會還原。
- 入口：設定頁「朋友給你的分享碼」貼碼或連結；打開 `?c=` 連結自動載入。結算頁有分享連結、複製、系統分享（支援時），並有「同一份題目再挑戰」。
